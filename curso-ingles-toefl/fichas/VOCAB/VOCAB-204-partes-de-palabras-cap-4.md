# Word parts: para, tele, culp, eu, ante, rect, fid, equ, pan, sym/syn (VOCAB-204)

> **Fuente:** *Building Vocabulary for College* — Smith, R. K., Chapter 4, Learning Word Parts from Context Clues, pp. 37–39.

## 🎯 Objetivo
Reconocer el significado de las partes de palabras del capítulo y usarlas para descifrar palabras nuevas en una lectura.

## 📘 Regla / Concepto
Cada parte se presenta con dos oraciones que ilustran su significado; el estudiante elige entre dos opciones y luego hace ejercicios de *matching* y *fill-ins*. La tabla resume el significado de cada parte (en inglés, como lo da el libro) con una palabra de ejemplo del texto.

## 🧩 Estructura / Fórmula
`parte de palabra` + `palabra conocida` → significado nuevo

## 💬 Ejemplos (del texto)
- A paralegal works alongside lawyers.
- Ted was the culprit who broke the vase.
- Harry Truman's presidency antedates John Kennedy's by eight years.
- Most people equate expensive cars with wealth.

## ⚠️ Errores comunes (clave TOEFL)
- ❌ Aplicar el prefijo a ciegas: *pre* significa 'before' en *preview*, pero no en *precise* ni *precious* → ✅ confirmar con el contexto.
- ❌ Confundir prefijos parecidos (p. ej., *ante-* 'before' vs *anti-* 'against') → ✅ memorizar en pares.

## 🔤 Vocabulario clave
| Palabra/colocación | Significado | Nota |
|---|---|---|
| para- | beside; beyond / al lado, más allá | paralegal |
| tele- | far; distant / lejos | telescope |
| culp | blameworthy; at fault / culpa | culprit |
| eu- | good; well / bueno, bien | eulogy |
| ante- | before / antes | antedates |
| rect | straight; correct / recto, correcto | rectangle |
| fid | faith / fe, confianza | confided |
| equ | equal / igual | equate |
| pan- | all / todo | Pan American |
| sym-, syn- | together with / con, junto | sympathy |

## 🧪 Práctica estilo TOEFL
```quiz
- tipo: vocab
  pregunta: "The two research stations are equidistant from the base camp, so each team walks the same number of kilometers. 'Equidistant' means"
  opciones: ["far from all places", "at an equal distance", "closer than expected", "at the correct angle"]
  respuesta: B
  explicacion: "equ = equal (Cap. 4) + distant → a igual distancia; lo confirma 'the same number of kilometers'."
```

## 🗒️ Notas / Excepciones
Palabras difíciles: paradigm, telepathy, culpable, euphemism, antediluvian, rectify, infidelity, equivocal, panacea, syndrome (pp. 39–42). No confundir ante- (before) con anti- (against, Cap. 5).
