# Obligation, necessity and advice (GRAM-237)

> **Fuente:** Intermediate English Grammar and Practice — Units 89–91 (pp. 92–94).

## 🎯 Objetivo
Distinguir *must / have to / mustn't / don't have to / needn't / should / ought to / had better*, y sus formas pasadas.

## 📘 Regla / Concepto
- *must* = obligación desde la opinión del hablante; *have to* = obligación externa o repetida. Solo *had to* para el **pasado** (no *must*).
- **mustn't** = prohibido (es importante no hacerlo) ≠ **don't have to / don't need to / needn't** = no es necesario.
- Preguntas con *do*: *Does he have to...?* (no *Has he to...?*). Informal: *have got to*.
- *have to* obligatorio tras otro modal o en forma *-ing*/participio/infinitivo: *They may have to be paid by cheque.*
- *needn't have* + V3 = se hizo, pero no era necesario; *didn't need to* = no era necesario (no se sabe si se hizo).
- *should / ought to* = obligación suave, consejo, opinión; *should have / ought to have* + V3 = debió hacerse y no se hizo.
- *had better* (+ base) = consejo para una situación concreta; negativo *had better not*. Nunca *have better*.

## 🧩 Estructura / Fórmula
- `must / have to / should / had better + base` · `ought to + base`
- `should have + V3` (crítica del pasado) · `needn't have + V3`

## 💬 Ejemplos (del texto)
- She had to catch the six o'clock train.
- You must not talk about politics.
- You don't have to learn any new typing skills.
- I needn't have waited until the game began.
- You'd better go tomorrow.

## ⚠️ Errores comunes (clave TOEFL)
- ❌ *Yesterday I must work late.* → ✅ *Yesterday I **had to** work late.*
- ❌ *You mustn't come if you don't want to.* (= no es necesario) → ✅ *You **don't have to** come...*
- ❌ *You should to see a doctor.* → ✅ *You should see a doctor.*
- ❌ *You have better leave.* → ✅ *You **had** better leave.*
- ❌ *You should have tell me.* → ✅ *You should have **told** me.*

## 🔤 Vocabulario clave
| Palabra/colocación | Significado | Nota |
|---|---|---|
| mustn't | no debes (prohibido) | |
| don't have to | no tienes que | no es necesario |
| had better | más vale que | consejo |
| needn't have | no hacía falta haber | |
