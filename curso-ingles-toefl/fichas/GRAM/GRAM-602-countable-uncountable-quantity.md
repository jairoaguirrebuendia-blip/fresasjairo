# Countable/uncountable y expresiones de cantidad (GRAM-602)

> **Fuente:** *Reward Pre-intermediate Resource Pack* — Macmillan, 1999, Worksheet 15 "A day in the diet of…", teacher's notes (s/p).

## 🎯 Objetivo
Elegir el cuantificador correcto según el sustantivo sea contable o incontable.

## 📘 Regla / Concepto
El libro lista: *some, any, a lot, (not) much/many, hardly any*.
- **many / (not) many** → contables plurales.
- **much / (not) much** → incontables (sobre todo en negativas y preguntas).
- **some / any / a lot (of) / hardly any** → ambos tipos (*some* en afirmativas; *any* en negativas/preguntas; *hardly any* = casi nada/ninguno).

## 🧩 Estructura / Fórmula
- `many + plural count noun` · `much + noncount noun` · `a lot of / some / any / hardly any + ambos`

## 💬 Ejemplos (del texto)
- Expresiones listadas: some, any, a lot, (not) much/many, hardly any.
- Ejemplos propios (el OCR de los menús es ilegible): *He doesn't eat much fruit.* / *She drinks a lot of coffee.* / *There aren't many vegetables in his diet.*

## ⚠️ Errores comunes (clave TOEFL)
- ❌ *much vegetables* → ✅ *many vegetables*
- ❌ *many informations / advices* → ✅ *much information / advice* (incontables en inglés)
- ❌ *a few water* → ✅ *a little water*

## 🔤 Vocabulario clave
| Palabra/colocación | Significado | Nota |
|---|---|---|
| hardly any | casi nada / casi ningún | valor negativo |
| a lot of | mucho(s) | contable e incontable |
| food, bread, fruit, meat | comida, pan, fruta, carne | normalmente incontables |

## 📝 Práctica
- Ref. libro: Worksheet 15, emparejar menús con personas y con comentarios de un médico.

## 🧪 Práctica estilo TOEFL
```quiz
- tipo: structure
  pregunta: "Desert plants need very ____ water to survive."
  opciones: ["few", "many", "little", "number of"]
  respuesta: C
  explicacion: "'Water' es incontable → little (poca). 'Few' y 'many' son para contables."
- tipo: error-id
  pregunta: "The library has {A|received} {B|much} {C|new books} {D|this year}."
  respuesta: B
  explicacion: "'Books' es contable plural → many (o a lot of), no much."
```
