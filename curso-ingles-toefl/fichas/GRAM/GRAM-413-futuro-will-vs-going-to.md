# Futuro con will vs going to (GRAM-413)

> **Fuente:** The English Tenses: Practical Grammar Guide — Williams, P., The Future — The Future Simple, secciones 30–32, 34.1–34.4, 35.2–35.3, s/p.

## 🎯 Objetivo
Distinguir *will* (decisión espontánea, predicción de opinión) de *be going to* (plan previo, predicción con evidencia).

## 📘 Regla / Concepto
El "future simple" tiene 4 estructuras (30): *will* + bare inf., *be going to* + bare inf., present simple + tiempo futuro, present continuous + tiempo futuro.
- **will:** eventos **no planeados** / respuesta a información nueva (34.1); **decisiones en el momento** (34.4); **predicciones sin evidencia**, basadas en opinión, a menudo con *probably, definitely, I think* (34.3); suena más personal o decidido.
- **going to:** eventos **planeados** antes de hablar (34.2); decisiones ya tomadas; **predicciones basadas en evidencia** presente o pasada (35.3) — suenan más seguras.
- La frontera es flexible: a veces ambos son posibles.

## 🧩 Estructura / Fórmula
`will (+ not) + bare infinitive` · `am/is/are (+ not) + going to + bare infinitive`

## 💬 Ejemplos (del texto)
- I**'ll answer** the phone. (in response to it ringing)
- He **is going to visit** his parents in Scotland. (already planned)
- It**'s going to rain** all night. (forecast / we can see it coming)
- We've run out of milk, I**'m going to buy** some more. / …I**'ll go buy** some more.
- The shop **will probably lose** money this month. (a guess)

## ⚠️ Errores comunes (clave TOEFL)
- ❌ *Look at those clouds! It will to rain.* → ✅ *It's going to rain.* (evidencia; y nunca *will to*)
- ❌ *She is going to visits us.* → ✅ *She is going to visit us.*
- ❌ *Shall you help me?* → ✅ *Will you help me?* (*shall* solo con *I/we* para ofrecer/sugerir)

## 🔤 Vocabulario clave
| Palabra/colocación | Significado | Nota |
|---|---|---|
| probably / definitely | probablemente / definitivamente | con *will*: *will probably* |
| I think… will | creo que… | predicción de opinión |
| look! / the forecast says | ¡mira! / el pronóstico dice | evidencia → *going to* |

```quiz
- tipo: structure
  pregunta: "Look at those dark clouds over the hills! It ____ any minute."
  opciones: ["will raining", "is going to rain", "rains", "is raining to"]
  respuesta: B
  explicacion: "Predicción basada en evidencia visible → 'be going to'."
- tipo: structure
  pregunta: "Woman: The phone is ringing and my hands are wet. Man: Don't worry, I ____ it."
  opciones: ["am going to answer", "answer", "will answer", "answered"]
  respuesta: C
  explicacion: "Decisión espontánea en respuesta a algo nuevo → 'will'."
- tipo: error-id
  pregunta: "{A|Shall} you {B|pass} me {C|that} dictionary, {D|please}?"
  respuesta: A
  explicacion: "'Shall' en preguntas solo con I/we para ofrecer o sugerir; para pedir algo a 'you' → 'Will'."
```

## 🗒️ Notas / Excepciones
El libro afirma (35.1) que *will* puede sugerir **determinación** (*I will finish this book this afternoon*) y *going to*, **certeza** o plan.
