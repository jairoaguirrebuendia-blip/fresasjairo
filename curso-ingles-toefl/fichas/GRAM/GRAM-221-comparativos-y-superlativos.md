# Comparatives and superlatives (GRAM-221)

> **Fuente:** Intermediate English Grammar and Practice — Units 35–37 (pp. 38–40).

## 🎯 Objetivo
Formar comparativos y superlativos correctamente, usar *than*, *the ... the ...*, *as ... as*, *the same as* y *like*, y evitar formas dobles (*more better*).

## 📘 Regla / Concepto
**Formas (Unit 35):**
- 1 sílaba: *-er / -est* (*cheaper, safest*); se duplica consonante final (*bigger*).
- 2 sílabas en *-y*: *-ier / -iest* (*happier, funniest*).
- La mayoría de 2 sílabas, las largas y los adverbios en *-ly*: *more / most* (*more careful, most seriously*). *early → earlier*.
- Irregulares: *good/well → better → best; bad/badly → worse → worst; far → farther/further; old → elder/eldest* (familia).
- *the* + superlativo ante sustantivo; *most* sin *the* ≈ *very*.

**Usos (Unit 36):**
- Comparativo + **than**; superlativo + *in/of* + grupo.
- Intensificadores: *much, far, a lot, a bit, slightly* + comparativo; *by far, easily* + *the* + superlativo.
- **The + comparativo..., the + comparativo**: *The smaller it is, the cheaper it is to post.*
- Progresión: *harder and harder, more and more expensive*.

**Otras formas (Unit 37):**
- *as + adj/adv + as*; negativo *not as/so ... as*; *almost / just / nearly as ... as*.
- *the same as* (no *the same than*); *be/look/seem + like*.
- *less / least* = lo contrario de *more / most*.
- Tras *as* / *than* / *like* con pronombre: objeto o posesivo (*as clever as him*).

## 🧩 Estructura / Fórmula
- `adj-er / more + adj + than` · `the + adj-est / most + adj + in/of`
- `the + comparative + S + V, the + comparative + S + V`
- `as + adj/adv + as` · `the same + (noun) + as`

## 💬 Ejemplos (del texto)
- She was much older than me.
- It was by far the worst hospital I had ever seen.
- The quicker we finish, the sooner we will go home.
- They are not as clever as they appear to be.
- Your bag is the same as mine.

## ⚠️ Errores comunes (clave TOEFL)
- ❌ *more better / more easier* → ✅ *better / easier*
- ❌ *the most fast* → ✅ *the fastest*
- ❌ *as tall than* → ✅ *as tall **as*** · ❌ *taller as* → ✅ *taller **than***
- ❌ *the same than* → ✅ *the same **as***
- ❌ *The more you practice, more you learn.* → ✅ *..., **the** more you learn.*

## 🔤 Vocabulario clave
| Palabra/colocación | Significado | Nota |
|---|---|---|
| by far the best | con mucho el mejor | |
| further / farther | más lejos | *further* también = adicional |
| the least skilled | el menos hábil | |
| more and more | cada vez más | |

## 🧪 Práctica estilo TOEFL
```quiz
- tipo: error-id
  pregunta: "Jupiter is {A|much} {B|more larger} than Earth and {C|has} a {D|stronger} gravitational field."
  respuesta: B
  explicacion: "Comparativo doble: 'larger' ya es comparativo; no se añade 'more'."
- tipo: structure
  pregunta: "____ a material is, the more heat it can store."
  opciones: ["Denser", "The denser", "The more dense than", "Densest"]
  respuesta: B
  explicacion: "Estructura 'the + comparativo ..., the + comparativo': 'The denser a material is, the more heat it can store'."
- tipo: error-id
  pregunta: "The climate of the island is {A|almost} {B|the same} {C|than} that of the {D|nearby} coast."
  respuesta: C
  explicacion: "Se dice 'the same as', no 'the same than'."
```
