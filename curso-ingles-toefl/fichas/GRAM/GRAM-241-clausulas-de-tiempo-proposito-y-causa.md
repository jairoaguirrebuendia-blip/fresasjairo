# Time, purpose and reason clauses (GRAM-241)

> **Fuente:** Intermediate English Grammar and Practice — Unit 96 "Time clauses", p. 99; Unit 97 "Purpose and reason clauses", p. 100.

## 🎯 Objetivo
Usar las conjunciones de tiempo, propósito y causa con los tiempos verbales correctos y sin confundir conjunción (+ cláusula) con preposición (+ sustantivo).

## 📘 Regla / Concepto
**Tiempo (Unit 96):** *after, as, as soon as, before, by the time, since, ever since, till/until, when, while*.
- Necesitan cláusula principal; pueden ir antes (con coma) o después.
- **Nunca futuro** en la cláusula de tiempo: presente o present perfect.
- Simultaneidad: *as, when, while* (acción interrumpida en continuo).
- *since*: past simple en la cláusula de tiempo + present perfect en la principal (*I've been in politics since I was at university*). *It is two weeks since I wrote.*
- Formal: se omite el sujeto y se usa participio: *before going, while parked*.

**Propósito (Unit 97):** *to / in order to / so as to* + base; negativo **in order not to / so as not to** (o *to avoid* + -ing). Con sujeto distinto: *so that / in order that* + modal (*can/will* presente; *could/would/might* pasado). *for* + sustantivo (*for fun*).
**Causa:** *because, since, as* + cláusula; *in case* = por si acaso (sin futuro).

## 🧩 Estructura / Fórmula
- `when / as soon as / until + present, ... will + base`
- `in order (not) to / so as (not) to + base`
- `so that + S + can/could + base`
- `because / since / as + S + V` · `in case + present`

## 💬 Ejemplos (del texto)
- As soon as we get tickets, we'll send them to you.
- He hadn't cried since he was a boy of ten.
- They went on foot, so as not to be heard.
- I have drawn a diagram so that my explanation will be clearer.
- I've got the key in case we want to go inside.

## ⚠️ Errores comunes (clave TOEFL)
- ❌ *I'll call you when I will arrive.* → ✅ *...when I **arrive**.*
- ❌ *He studied for pass the exam.* → ✅ *...**to** pass / **in order to** pass...*
- ❌ *in order to not be heard* → ✅ *in order **not to** be heard*
- ❌ *I've underlined it to be easier.* (sujeto distinto) → ✅ *...**so that it will be** easier.*
- ❌ *in case she will arrive* → ✅ *in case she **arrives***

## 🧪 Práctica estilo TOEFL
```quiz
- tipo: structure
  pregunta: "Many desert plants have small leaves ____ lose too much water."
  opciones: ["so as not to", "in order to not", "for not", "so that not"]
  respuesta: A
  explicacion: "Propósito negativo con infinitivo: 'so as not to' (o 'in order not to'). 'not' va antes de 'to'."
- tipo: error-id
  pregunta: "The experiment {A|will continue} {B|until} the researchers {C|will collect} {D|enough} data."
  respuesta: C
  explicacion: "En la cláusula de tiempo ('until') no se usa futuro: 'until the researchers collect'."
- tipo: structure
  pregunta: "____ it was a national holiday, all the government offices were closed."
  opciones: ["Because of", "Since", "Despite", "In order that"]
  respuesta: B
  explicacion: "Sigue una cláusula (sujeto + verbo) que da la razón → conjunción 'Since'. 'Because of' y 'Despite' exigen sustantivo."
```
