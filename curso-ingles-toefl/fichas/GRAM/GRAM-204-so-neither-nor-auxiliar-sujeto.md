# So/neither + auxiliary + subject (GRAM-204)

> **Fuente:** Intermediate English Grammar and Practice — Unit 10 "Short answers", p. 13.

## 🎯 Objetivo
Usar respuestas cortas con el auxiliar correcto y la inversión tras *so / neither / nor* para indicar que algo también aplica a otra persona.

## 📘 Regla / Concepto
- Las respuestas cortas usan pronombre + auxiliar, modal o *be* (*Yes, she does*). Si la frase original no tiene auxiliar, se usa *do/does/did*.
- Para decir "yo también / yo tampoco": *so* (afirmativo) y *neither / nor* (negativo) + **auxiliar + sujeto** (inversión), con el mismo auxiliar del enunciado.
- Con *not ... either* **no** hay inversión: *We don't either.*
- Tras *think, hope, expect, suppose, imagine* se usa *so* (*I hope so*); negativos: *I don't think so*, pero *I hope not / I'm afraid not*.

## 🧩 Estructura / Fórmula
- `So + aux + subject` · `Neither/Nor + aux + subject`
- `Subject + negative aux + either`

## 💬 Ejemplos (del texto)
- 'You were different then.' – 'So were you.'
- 'I don't normally drink at lunch.' – 'Neither do I.'
- 'I can't do it.' – 'Nor can I.'
- 'He doesn't understand.' – 'We don't either.'
- 'Is it raining?' – 'I'm afraid so.'

## ⚠️ Errores comunes (clave TOEFL)
- ❌ *Neither I do.* → ✅ *Neither **do I**.*
- ❌ *So I am.* (para "yo también") → ✅ *So **am I**.*
- ❌ *Neither don't I.* (doble negación) → ✅ *Neither do I.*
- ❌ *I don't hope so.* → ✅ *I hope not.*

## 🔤 Vocabulario clave
| Palabra/colocación | Significado | Nota |
|---|---|---|
| so do I | yo también | afirmativo |
| neither / nor do I | yo tampoco | negativo, con inversión |
| not ... either | tampoco | sin inversión |
| I'm afraid so / not | me temo que sí / no | |

## 🧪 Práctica estilo TOEFL
```quiz
- tipo: structure
  pregunta: "Maria had never visited Asia before, and ____."
  opciones: ["neither had her husband", "neither her husband had", "her husband hadn't neither", "so had her husband"]
  respuesta: A
  explicacion: "Enunciado negativo ('never') → 'neither' + auxiliar 'had' + sujeto (inversión)."
- tipo: error-id
  pregunta: "Lions {A|hunt} mainly at night, and {B|so} {C|tigers do} {D|in most regions}."
  respuesta: C
  explicacion: "Tras 'so' se invierte: 'so do tigers'."
```
