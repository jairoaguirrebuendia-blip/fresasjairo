# Agreement con one of, a number of, every, there (GRAM-101)

> **Fuente:** Oxford Guide to English Grammar — Eastwood, J., Chapter 18, §153, pp. 193–194.

## 🎯 Objetivo
Resolver la concordancia en sujetos con expresiones de cantidad, pronombres indefinidos y `there is/are`.

## 📘 Regla / Concepto
- **one of + plural** → verbo **singular** (el sujeto es *one*).
- **a number of / the majority of / a lot of + plural** → verbo **plural** (expresan cantidad).
- **the number of** (= la cifra) → **singular**. **amount** concuerda con *amount*.
- Fracciones: el verbo concuerda con el sustantivo que sigue (*three quarters of a potato is / half the plants were*).
- **every, each** y compuestos **everyone, someone, anything, nothing…** → **singular**. Pero *all / some + plural* → plural. Si *each* va **después** de un sujeto plural → plural.
- **none of / neither of / either of / any of + plural**: singular o plural (plural = más informal; en el examen, el singular es la opción "segura").
- **there + be** concuerda con el **complemento** que sigue.

## 🧩 Estructura / Fórmula
`One of the + N plural + V singular` · `A number of + N plural + V plural` · `The number of + N plural + V singular` · `There is + N sing / There are + N pl`

## 💬 Ejemplos (del texto)
- One of these letters **is** for you.
- A large number of letters **were** received. / The number of letters we receive **is** increasing.
- Every pupil **has** to take a test. / All the pupils **have** to take a test.
- The pupils each **have** to take a test.
- There **was** an accident. There **were** some accidents.

## ⚠️ Errores comunes (clave TOEFL)
- ❌ *One of the most important inventions **were**…* → ✅ *…**was**…*
- ❌ *The number of applicants **have** doubled.* → ✅ *…**has** doubled.*
- ❌ *Each of the students **have** a locker.* → ✅ *…**has**…*
- ❌ *There **is** many reasons…* → ✅ *There **are** many reasons…*

## 🔤 Vocabulario clave
| Palabra/colocación | Significado | Nota |
|---|---|---|
| a number of | varios, muchos | + plural |
| the number of | el número (la cifra) de | + singular |
| the majority of | la mayoría de | plural con N plural |
| an amount of | una cantidad de | con incontables; concuerda con amount |

## 🗒️ Notas / Excepciones
- *Who/What* como sujeto → singular: *Who knows the answer?* Con *which/what + N*, concuerda con el sustantivo.
- Informalmente se oye *There's some friends of yours outside*, pero no es la forma de examen.
