# Cuantificadores: many, much, few, little, fewer, less (GRAM-131)

> **Fuente:** Oxford Guide to English Grammar — Eastwood, J., Chapter 21, §177, pp. 220–221; Chapter 26, §220, pp. 282–283.

## 🎯 Objetivo
Emparejar cada cuantificador con sustantivos contables plurales o incontables.

## 📘 Regla / Concepto
- **many / (a) few / fewer / fewest / a number of** → **contables plurales**.
- **much / (a) little / less / least / an amount of / a great deal of** → **incontables**.
- **a lot of / lots of / plenty of / enough / more / most / some** → ambos.
- *a few / a little* = algunos (positivo). *few / little* (sin *a*) = pocos (negativo, "casi ninguno"). *only a few* = menos de lo esperado; *quite a few* = bastantes.
- *many/much* tras *very, so, too, as, how* (no *a lot of*).
- *fewer* con plurales es la regla; *less cars* es informal y conviene evitarlo.

## 🧩 Estructura / Fórmula
`many / few / fewer + N plural` · `much / little / less + N incontable`

## 💬 Ejemplos (del texto)
- There aren't **many** trains on a Sunday. / There isn't **much** traffic on a Sunday.
- Yes, there are **a few** night clubs in the city. / I've still got **a little** money.
- No, there are **few** tourists here. (= not many)
- There are **fewer** cars on the road in winter.
- There's **less** music on the radio at weekends.

## ⚠️ Errores comunes (clave TOEFL)
- ❌ *Less people attended this year.* → ✅ ***Fewer** people…*
- ❌ *How much students…?* → ✅ *How **many** students…?*
- ❌ *There is very few information.* → ✅ *There is very **little** information.*
- ❌ *a great deal of problems* → ✅ ***a great many / a large number of** problems*

## 🔤 Vocabulario clave
| Palabra/colocación | Significado | Nota |
|---|---|---|
| a great deal of | mucho/a | incontable |
| a great many | muchísimos | plural, formal |
| numerous | numerosos | plural |
| hardly any | casi ningún | ambos |
